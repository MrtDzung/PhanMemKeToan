---

## Summary

Enable the "Xuất Excel" button on the Account Tree toolbar to export the Vietnamese Chart of Accounts to a `.xlsx` file using **SheetJS (xlsx)** — fully client-side, no new API endpoint.

The work consists of:
1. Install the `xlsx` npm package
2. Create a shared `ExcelExportService` in `core/services/`
3. Wire the toolbar button (already exists, currently `[disabled]="true"`) to emit an output event and show loading state
4. Handle the output in the page component to call the service

**No backend changes. No new API endpoint. No store method added. No new data models.**

## Phase 0: Research

No external unknowns. All technologies established and decisions already resolved in spec.

**Resolved decisions**:

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Excel engine | SheetJS `xlsx` (client-side) | Spec pre-decided; no backend cost; 500-row performance well within target |
| Export logic location | Standalone `ExcelExportService` in `core/services/` | 15 accounting modules all need Excel export in future; shared service avoids duplication |
| Store involvement | None — page reads `filteredAccounts()` directly | Export is a presentation concern, not a data concern; store SRP preserved |
| Loading state location | `isExporting = signal(false)` in page component | Page owns the async operation; toolbar receives `[isExporting]` as input |
| SheetJS async wrapping | `setTimeout(resolve, 0)` before CPU work | Allows Angular to render spinner before synchronous SheetJS processing blocks main thread |
| `CurrencyCode` gap | Map `isPostableInForeignCurrency` → label | `AccountTreeNodeDto` has no `currencyCode`; `true` → "Ngoại tệ", `false` → blank |
| `AccountCategoryKind` → "Loại TK" | Map enum to Vietnamese debit/credit labels | Enum is `Debit=0/Credit=1/Mixed=2`; maps to "Dư Nợ" / "Dư Có" / "Lưỡng tính" |
| Parent code resolution | Build `Map<accountId, accountNumber>` from `store.accounts()` | Filtered list may exclude parents; raw `accounts` signal has full roster |
| Header color | `const EXCEL_PRIMARY_COLOR = '1B5E9E'` in service | Design token `--primary: #1B5E9E`; constant isolates the value from component styles |

### 1.1 Existing Model Analysis (no model changes)

`AccountTreeNodeDto` (in `account.models.ts`) fields available for export:

| DTO field | Excel column | Vietnamese header | Notes |
|-----------|-------------|-------------------|-------|
| `accountNumber` | A | Số hiệu TK | Correct field name (not `accountCode`) |
| `accountName` | B | Tên tài khoản | |
| `accountCategoryKind` | C | Loại TK | Map via `CATEGORY_KIND_LABELS` |
| `grade` | D | Cấp | Right-aligned number |
| `parentId` → lookup | E | Tài khoản mẹ | Resolve via `Map<accountId, accountNumber>` from `store.accounts()` |
| `isPostableInForeignCurrency` | F | Tiền tệ | `true` → "Ngoại tệ", `false` → blank |

**Key field name correction**: The spec references `accountCode` but the actual DTO field is `accountNumber`. The service must use `accountNumber`.

### 1.2 ExcelExportService Contract

```typescript
// src/webapp/src/app/core/services/excel-export.service.ts
import { Injectable } from '@angular/core';
import { AccountTreeNodeDto } from '../features/di/models/account.models';

@Injectable({ providedIn: 'root' })
export class ExcelExportService {
  /**
   * Export a flat list of accounts to .xlsx and trigger browser download.
   * @param accounts   filtered accounts to export (from store.filteredAccounts())
   * @param allAccounts all accounts (from store.accounts()) — needed for parent lookup
   */
  exportAccountsToExcel(
    accounts: AccountTreeNodeDto[],
    allAccounts: AccountTreeNodeDto[]
  ): void { ... }
}
```

**Internal constants** (all in service, none in component):
```typescript
const EXCEL_PRIMARY_COLOR = '1B5E9E';   // --primary design token
const SHEET_NAME = 'Danh mục tài khoản';
const FILE_PREFIX = 'danh-muc-tai-khoan_';

const COLUMN_HEADERS = [
  'Số hiệu TK', 'Tên tài khoản', 'Loại TK',
  'Cấp', 'Tài khoản mẹ', 'Tiền tệ', 'Trạng thái'
];

const CATEGORY_KIND_LABELS: Record<number, string> = {
  0: 'Dư Nợ',    // AccountCategoryKind.Debit
  1: 'Dư Có',    // AccountCategoryKind.Credit
  2: 'Lưỡng tính' // AccountCategoryKind.Mixed
};
```

**SheetJS workbook steps**:
1. Build `Map<accountId, accountNumber>` from `allAccounts`
2. Map each account to a row array `[accountNumber, accountName, categoryLabel, grade, parentNumber|'', currencyLabel, statusLabel]`
3. `XLSX.utils.aoa_to_sheet([COLUMN_HEADERS, ...rows])`
4. Style header row: `bold: true`, `fill: { fgColor: { rgb: EXCEL_PRIMARY_COLOR } }`, `font: { color: { rgb: 'FFFFFF' } }`
5. Set column widths (`wch`) based on content — approximate: `[15, 40, 12, 6, 15, 10, 12]`
6. Set right-align on column D (Cấp): numeric cell style `{ alignment: { horizontal: 'right' } }`
7. `XLSX.utils.book_new()` → `XLSX.utils.book_append_sheet()` → `XLSX.writeFile(wb, filename)`

> **SheetJS cell styling note**: Cell styling (bold headers, colors) requires the `xlsx-js-style` package or `xlsx-style` fork — the base `xlsx` package does not support cell styles in the free version. **Decision**: Use `xlsx-js-style` (a drop-in replacement for `xlsx` that adds styling support). Install as `npm install xlsx-js-style`. Import as `import * as XLSX from 'xlsx-js-style'`.

### 1.4 Page Component Contract Changes

```typescript
// New injection in AccountTreePageComponent:
private readonly excelExportService = inject(ExcelExportService);
readonly isExporting = signal(false);

// New handler:
async onExportExcel(): Promise<void> {
  this.isExporting.set(true);
  await new Promise<void>(resolve => setTimeout(resolve, 0)); // flush UI
  try {
    this.excelExportService.exportAccountsToExcel(
      this.store.filteredAccounts(),
      this.store.accounts()
    );
  } catch {
    this.messageService.add({
      severity: 'error',
      summary: 'Lỗi',
      detail: 'Không thể xuất file Excel. Vui lòng thử lại.'
    });
  } finally {
    this.isExporting.set(false);
  }
}

// Template change — add two bindings to <app-account-tree-toolbar>:
(exportExcel)="onExportExcel()"
[isExporting]="isExporting()"
```

## Known Gaps & Decisions

### Gap 1: `currencyCode` not in `AccountTreeNodeDto`

The spec requested "Tiền tệ" column with actual currency codes. `AccountTreeNodeDto` only exposes `isPostableInForeignCurrency: boolean`.

**Decision**: Map `isPostableInForeignCurrency`:
- `true` → "Ngoại tệ" (accepts foreign currency)
- `false` → blank (VND default, no label needed)

This is sufficient for the export. If a full currency code list is needed in future, the API endpoint must be extended — but that's out of scope for this feature.

### Gap 2: SheetJS base `xlsx` does not support cell styling

The base `xlsx` package (`sheetjs`) does not support `cellStyles` in the community edition. Cell styling (bold headers, colored header background) requires either:
- `xlsx-js-style` (maintained fork) — **recommended**
- `exceljs` (heavier, but full-featured) — overkill for this feature

**Decision**: Use `xlsx-js-style` (drop-in compatible with `xlsx` API, adds styling).

### Gap 3: `AccountCategoryKind` vs spec's "AccountType" labels

The spec mentions "Tài sản", "Nguồn vốn", "Doanh thu", "Chi phí" as `AccountType` values. The actual model uses `accountCategoryKind: AccountCategoryKind` (Debit/Credit/Mixed enum). These are different taxonomies.

**Decision**: Map `AccountCategoryKind` to debit/credit nature labels:
- `0 (Debit)` → "Dư Nợ"
- `1 (Credit)` → "Dư Có"
- `2 (Mixed)` → "Lưỡng tính"

This is the correct mapping for what the data actually represents. The spec's "Tài sản/Nguồn vốn" taxonomy is not exposed in the current DTO.
