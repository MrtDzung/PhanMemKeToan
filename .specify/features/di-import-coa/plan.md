# Implementation Plan: Import COA Chuẩn

**Branch**: `feature/sys-auth-tenant` (active) | **Date**: 2026-04-18  
**Spec**: `.specify/features/di-import-coa/spec.md`  
**Module**: DI — account-tree sub-module

---

## Summary

Add a guided 2-step import dialog for Vietnamese standard Chart of Accounts (TT99 / TT133). All API and store infrastructure already exists — the work is purely frontend UI: one new `ImportCoaDialogComponent` + a new toolbar button that opens it. The dialog uses `p-steps` + `p-dialog` (PrimeNG), calls `AccountTreeStore.importCoa()`, and displays a result summary panel after import.

No backend changes. No new data models. No new API contracts.

---

**Language/Version**: TypeScript 5.4, Angular 18 (standalone components + signals)

**Resolved decisions**:

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Dialog visibility management | Parent-owned `signal<boolean>` bound to `[visible]`/`(visibleChange)` | Keeps dialog stateless on visibility; consistent with PrimeNG pattern |
| Dialog state reset trigger | Reset on `(onShow)` event of `p-dialog` | Ensures fresh state on every open without exposing `open()` method to parent |
| Result display after import | Replace stepper content in-place (not a new route/view) | Spec FR-06: "p-steps stepper view must be replaced entirely with a result summary panel within the same dialog" |
| Store type annotation fix | Minimal: change return type to `Promise<ImportCoaResultDto>` | Existing return value already includes `errors[]` but TypeScript type hides it |

## Phase 2: Component Architecture

### 2.1 ImportCoaDialogComponent

**File**: `src/webapp/src/app/features/di/account-tree/components/import-coa-dialog/import-coa-dialog.component.ts`

#### Inputs / Outputs

```typescript
// Visibility controlled by parent
visible = input<boolean>(false);
visibleChange = output<boolean>();
```

#### Internal Signal State

```typescript
activeStep   = signal<number>(0);                              // 0 = Step 1, 1 = Step 2
selectedStd  = signal<'TT99' | 'TT133' | null>(null);
resolution   = signal<'skip' | 'overwrite'>('skip');
importing    = signal<boolean>(false);
result       = signal<ImportCoaResultDto | null>(null);
importError  = signal<string | null>(null);
```

#### Computed Signals

```typescript
// Show inline p-message warning (FR-03)
showOverwriteWarn = computed(() => this.resolution() === 'overwrite');

// Step 1 "Next" button enabled only if a standard is selected
canNext = computed(() => this.selectedStd() !== null);

// Step 2 "Import" button: enabled only when not importing and standard is selected
canImport = computed(() => !this.importing() && this.selectedStd() !== null);

// Dialog is not closable during import (FR-09)
isClosable = computed(() => !this.importing());

// Show result panel instead of stepper (FR-06)
showResultPanel = computed(() => this.result() !== null || this.importError() !== null);

// Selected standard display object
selectedStandard = computed(() => COA_STANDARDS.find(s => s.id === this.selectedStd()) ?? null);
```

#### State Reset on Open

Reset in `(onShow)` event handler (PrimeNG fires this when dialog becomes visible):

```typescript
onDialogShow(): void {
  this.activeStep.set(0);
  this.selectedStd.set(null);
  this.resolution.set('skip');
  this.importing.set(false);
  this.result.set(null);
  this.importError.set(null);
}
```

#### Import Method

```typescript
async executeImport(): Promise<void> {
  const std = this.selectedStd();
  if (!std) return;

  this.importing.set(true);
  try {
    const res = await this.store.importCoa(std, this.resolution());
    this.result.set(res as ImportCoaResultDto);  // cast needed until store type is fixed
    // Tree reloads automatically inside store.importCoa() (FR-07)
  } catch (err: unknown) {
    const msg = (err as any)?.error?.detail ?? 'Nhập danh mục thất bại. Vui lòng thử lại.';
    this.importError.set(msg);
  } finally {
    this.importing.set(false);
  }
}
```

#### Template Structure

```
<p-dialog [visible]="visible()" (visibleChange)="visibleChange.emit($event)"
          [closable]="isClosable()" [modal]="true" [draggable]="false"
          header="Nhập danh mục tài khoản chuẩn" [style]="{width: '520px'}"
          (onShow)="onDialogShow()">

  <!-- STEPPER AREA (shown when showResultPanel() is false) -->
  @if (!showResultPanel()) {
    <p-steps [model]="stepItems" [activeIndex]="activeStep()" [readonly]="true" />

    <!-- Step 1: Chọn chuẩn -->
    @if (activeStep() === 0) {
      <!-- Two radio cards for TT99 and TT133 -->
      <!-- Each card shows: name, legalReference, description, accountCount -->
    }

    <!-- Step 2: Tùy chọn nhập -->
    @if (activeStep() === 1) {
      <!-- Radio group: Bỏ qua | Ghi đè -->
      <!-- Inline p-message [severity]="'warn'" shown when showOverwriteWarn() -->
      <!-- Preview: "Sẽ nhập ~X tài khoản theo [standard]" -->
      <!-- Loading spinner shown when importing() -->
    }
  }

  <!-- RESULT PANEL (shown when showResultPanel() is true) -->
  @if (showResultPanel()) {
    @if (result(); as r) {
      <!-- Imported count: green (--positive) -->
      <!-- Skipped count: gray (--text-secondary) -->
      <!-- Overwritten count: orange (--warning) -->
      <!-- Error list (if r.errors.length > 0) -->
    }
    @if (importError(); as err) {
      <p-message severity="error" [text]="err" />
    }
  }

  <ng-template pTemplate="footer">
    <!-- FOOTER: step-aware button set -->
    @if (!showResultPanel()) {
      @if (activeStep() === 0) {
        <p-button label="Hủy" severity="secondary" [disabled]="importing()"
                  (onClick)="visibleChange.emit(false)" />
        <p-button label="Tiếp theo" icon="pi pi-arrow-right" iconPos="right"
                  [disabled]="!canNext()" (onClick)="activeStep.set(1)" />
      }
      @if (activeStep() === 1) {
        <p-button label="Quay lại" icon="pi pi-arrow-left" severity="secondary"
                  [disabled]="importing()" (onClick)="activeStep.set(0)" />
        <p-button label="Nhập" icon="pi pi-download" [loading]="importing()"
                  [disabled]="!canImport()" (onClick)="executeImport()" />
      }
    }
    @if (showResultPanel()) {
      <p-button label="Đóng" (onClick)="visibleChange.emit(false)" />
    }
  </ng-template>
</p-dialog>
```
